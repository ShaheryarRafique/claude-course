# Claude Zero to Master: Course Blueprint

This is the reference document for the whole course. Read it before recording anything.

## The Promise

By the end of this course a complete beginner can use, automate, and build with Claude across all three of its surfaces (the chat app, Claude Code, and the API), and knows how to turn those skills into real work or income.

Say this in the opening lesson so students know exactly what they are signing up for.

## Audience and Language

The course is for working professionals and students across industries, with a focus on South Asia. Skill levels are mixed, from people who have never used an AI tool to working developers.

The course is taught in clear, simple English. Technical terms are introduced slowly and explained the first time they appear. The tone is friendly and practical, like a mentor sitting next to the student, not a lecturer.

## Course Structure: One Path That Branches

Everyone follows the same path at the start. Later it branches by skill level so nobody is bored and nobody is lost.

| Track | Who it is for | Modules |
| --- | --- | --- |
| Everyone | All students | 1, 2, 3, 4, 5, 8 |
| Developer (optional) | Those who want to build with code | Modules 6 and 7 |

The eight modules and their names:

1. Get Started with Claude
2. Master the Claude App
3. Prompt Like a Pro
4. Put Claude to Work
5. Automate with Claude Cowork (Skills, connectors, and the Cowork agent)
6. Build with Claude Code
7. Build Real AI Apps
8. Ship and Earn

Each module carries a small on screen label telling the student whether it is essential or optional for them. Beginners are told plainly when a module is optional for them.

## How Every Lesson Is Built

Each lesson follows the same five step rhythm. Keeping the rhythm identical makes recording predictable and makes the course easy to follow.

1. Hook. Open with the result the student will be able to produce by the end of the lesson. Thirty to sixty seconds.
2. Concept. Explain one idea clearly. One idea per lesson, no overload. Two to five minutes.
3. Demonstration. Do it live on screen with a real example.
4. Practice. Pause and have the student do it themselves.
5. Recap and earning note. Three quick takeaways, then one line on how this skill earns money.

## Mindset Spine

Module 1 teaches a simple mental model for working with AI, based on Anthropic's AI fluency framework: four habits of delegation, description, discernment, and diligence. In plain terms, decide what to hand to Claude, describe it well, judge the result, and stay careful and honest. Later modules refer back to these habits so the course has a spine, not just a list of tips.

Retention is supported by:

- A quick, useful result inside Module 1 so students feel progress early.
- A ten second recap of the previous module at the start of each new one.
- A short project at the end of every module so students build, not just watch.
- A three question review at the end of each module.
- A downloadable one page summary for each module.
- A short graded assessment at the end of the course, and a certificate the student can show employers.

The course rises in difficulty across the eight modules, moving from understanding what Claude is, to applying it at work, to building with it.

## Earning Thread

For this audience, the first question is usually how a skill turns into income. Every module ends with a concrete earning angle rather than leaving money to the final module. Common angles reinforced throughout:

- Freelancing on platforms such as Fiverr and Upwork with faster delivery.
- Offering setup and automation services to local businesses.
- Content creation.
- Listing Claude and AI skills to win jobs.
- Building and selling small tools and agents.

Module 8 covers earning in full, with templates and pricing.

## What Is Current (verified August 2026)

Keep the course accurate to these facts on the day you record.

- Chat app: Projects, Artifacts, persistent Memory (now on the free tier too), web search, Skills, connectors for Gmail, Drive, Slack, GitHub and Notion, Claude in Chrome, voice, and extended thinking.
- Cowork: a desktop agent that carries out multi step tasks on the computer across areas such as finance, legal, marketing, data analysis, and research. Covered in Module 5.
- Claude Code: project instructions files, Skills, subagents, hooks, slash commands, plugins, connectors, and workflows that fan out multiple agents.
- API and Agent SDK: current models are Opus 4.8, Sonnet 4.6, Haiku 4.5, and Fable 5. Tool use, streaming, prompt caching for large savings, a one million token context window, and a batch option for cheaper bulk work.
- Prompt engineering now splits into everyday prompting, which anyone can do, and production context engineering, which is a real skill.

Teach students to always pick the latest and most capable model rather than memorising a name, because names and prices change. Re verify model names and pricing the week you record.

## Deliverables

1. This blueprint.
2. The full lesson map in `01-LESSON-MAP.md`, covering all eight modules, every lesson, timing, outcome, demonstration, and practice task.
3. Recording scripts, one file per module, in `scripts`.
4. Practice tasks and projects, one file per module, in `exercises`.
5. Slide outlines, one file per module, in `slides`.
6. A one page summary for each module, in `resources`.

Build order: finish the lesson map, then produce slides, scripts, exercises, and summaries module by module so there is always something ready to record.

## Studio Notes

- Record in module order, and within a module, in lesson order.
- Keep each lesson between five and twenty minutes so a fumble is easy to re record.
- Show the screen with your face in a small corner during demonstrations.
- Keep a demo account on a paid plan so paid features are visible.
- Restart a lesson cleanly rather than editing heavily.
- Use a short standard opening and closing for every lesson so the course feels consistent.
