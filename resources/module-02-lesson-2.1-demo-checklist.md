# Lesson 2.1 — Demo checklist ("Make Claude more powerful")

Two things to have ready before you hit record. Both live on the "Turn on the right tool" slide.

## Demo 1 — Web search (required, this is the one the exercise leads with)

Before recording:
- [ ] Confirm web search is available on your account/plan and currently toggled where you expect (UI location shifts, check same day).
- [ ] Pick a real "this week" topic in advance so you're not searching live for an idea. Something with a clean, clickable source works best on screen (a product launch, a sports result, a market move).
- [ ] Have the PROMPT ready to paste, don't type it live:
  > Search the web for the latest news on [topic] this week, and give me three points with a link for each.
- [ ] Know which citation link you'll click before you click it, so you land on a legible page, not a broken one.

On screen:
- [ ] Turn the toggle on visibly before sending the prompt.
- [ ] Send the prompt, let the three points render.
- [ ] Click one citation link. Let the page load. This is the "checkable source" payoff, don't rush past it.

## Demo 2 — Research (optional, "takes a few minutes")

Before recording:
- [ ] Confirm your account has Research access (paid plan, web search on) — verify same day, this gate is one of the fastest-drifting facts in the deck.
- [ ] Pick a question you genuinely want answered, so the result reads as real rather than a canned demo.
- [ ] Have the PROMPT ready:
  > Research [a question you care about] and give me a short, cited report with the key findings.
- [ ] Decide in advance whether you'll run this live (it can take several minutes) or cut to a pre-run result and narrate it. If cutting to a pre-run result, generate it before the session so you're not waiting on camera.

## Day-of-recording fact recheck

These are the claims flagged as fastest-drifting in the fact-check pass — glance at claude.com/pricing and the effort docs right before you record:
- [ ] Free vs. paid model access (Free is a shared usage pool now, not a hard Haiku/Sonnet-only lock).
- [ ] Whether Research still requires a paid plan.
- [ ] Current model names in the capability ladder (Haiku / Sonnet / Opus / Fable).
- [ ] That Haiku still doesn't support the effort parameter.

## After the demo

- [ ] Trim dead air from the Research wait time in editing if you ran it live.
- [ ] Confirm the citation link you clicked is still live before publishing (pages get taken down).
