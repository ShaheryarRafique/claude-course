# Module 2 — Real Beginner Questions (from student-asker)

The actual questions a South Asian beginner asks, grouped by feature. Use these to enrich lesson speaker notes and the Common Questions slide. Answer the biggest ones on screen, the rest in notes.

## Conversations (edit, branch, regenerate)
- If I edit my old message, is the previous chat gone, or can I go back? (No, it lives under the version arrows.)
- Is the old answer lost when I regenerate? What if the first was better?
- Does "branch" mean I copied the whole chat?
- Does regenerating use my daily limit?
- How do I find a chat from last week?

## Files and images
- Is my file private, or used to train the AI?
- Max file size? It says too big.
- Can I upload Excel or Word, or only PDF?
- Will it read a scanned document or handwriting?
- Is it safe to upload personal data (CNIC, salary)?
- How many files at once?

## Web search
- Free or paid? How do I turn it on?
- Does it browse live like Google, or use old info?
- Can I trust it? Will it give links?

## Triad (search vs think vs research)
- I genuinely do not know which to use when.
- Does extended thinking go online too?
- Can I turn on all three at once?
- For a normal homework question, do I need any of these?

## Model and effort
- Which model is best, and why not always use it?
- Is the smartest model paid only? Which model am I on if free?
- What does "effort" mean? Is more always better?
- How do I know which model I am talking to?

## Artifacts
- What is an Artifact exactly?
- Can I really build a working app with no coding?
- If I publish, can anyone see it, including my prompts or name?
- Do people need a Claude account or to pay to open it?
- Can I edit or unpublish after publishing?

## Projects
- What is the difference between instructions and knowledge base? They sound the same.
- Do I repeat instructions every chat, or does the Project remember for all chats?
- Do all chats in the Project read the uploaded files automatically?
- Projects paid only? Is my Project data private?

## Memory
- What are the three layers, and what is remembered where?
- Can I see and delete what it saved about me?
- Does a new chat forget everything, or still know me?
- Can one Project's memory leak into another?

## Voice and mobile
- Does the app do everything the website does?
- Will it understand my accent? Does voice work in Urdu or Hindi?
- Does voice use extra limit, data, or battery? Is it recording me?
- Are chats synced between phone and laptop?

## Cross-cutting (naive but real)
- Is all of this actually free, or will it ask for my card?
- If I use it for an assignment or report, is that cheating?
- Will my work or ideas get leaked or stolen?
- What happens in incognito? If my internet cuts off mid-answer?
- If the answer is wrong and I submit it, how do I know when to trust it?
