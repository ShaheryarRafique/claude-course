# Module 4 — The 4D Framework, in Depth (build plan)

Source: Anthropic AI Fluency (Dakan/Feller) + practitioner guides + course-structure research. Built 2026-09-16.
Decisions: single module (all 4 Ds + capstone) · build from researched plan · teach FULL sub-competencies.

## Crux
Module 3 named the four Ds and showed how they connect. Module 4 makes them a working habit by running ONE real project through all four: Delegation → (Describe ⇄ Discern) → Diligence. Students leave with a finished, verified deliverable.

## Model taught throughout
- Bookends: Delegation (decide at the start) and Diligence (own at the end) bracket the middle.
- Engine: Description ↔ Discernment loop = Describe → Discern → Refine → Integrate.
- `[ Delegation → ( Describe ⇄ Discern ) → Diligence ]`

## Through-line project (the spine)
Each student picks ONE real, medium, multi-step task (~1 hr, something they care about) and carries it through every lesson. Demo example on screen: a one-page resume. Menu offered: resume, small event, study plan, side-project page, newsletter.

## Lesson order (Anthropic's, time-weighted: Delegation & Diligence heavy; Discernment short)
1. 4.1 Delegation — 3 modes + 3 sub-parts (Problem/Goal Awareness, Platform Awareness, Task Delegation) → make your delegation plan
2. 4.2 Description — 3 sub-parts (Product, Process, Performance) → write your first prompt
3. 4.3 Six prompting techniques + Bad Prompt Makeover demo (builds on Module 1)
4. 4.4 Discernment — fluent ≠ correct; 3 sub-parts (Product, Process, Performance) → judge your draft
5. 4.5 The Describe–Discern loop — the engine + the P/P/P mirror → loop 3 rounds
6. 4.6 Diligence — 3 sub-parts (Creation, Transparency, Deployment) → fact-check + finalize
7. 4.7 Putting it together (capstone) — all four on the project, minimal new content

## Sub-competencies (taught in full)
- Delegation: Problem/Goal Awareness · Platform Awareness · Task Delegation
- Description: Product · Process · Performance (Performance = Agency-mode behavior)
- Discernment: Product · Process · Performance (mirrors Description one-to-one)
- Diligence: Creation (ethics/bias/data) · Transparency (disclose) · Deployment (fact-check/test)

"By the end, you will be able to [Bloom verb] [observable artifact] [+ justify your choice]."
